# Simple Task

> Um gerenciador de tarefas simples, rápido e objetivo, desenvolvido para organizar atividades, prioridades e manutenções em um único lugar.

---

## 📋 Sobre o projeto

O **Simple Task** é um sistema de gerenciamento de tarefas inspirado em conceitos de ferramentas como o Trello, mas com uma proposta mais simples e direta.

O objetivo é oferecer uma interface limpa para:

- Criar e organizar tarefas;
- Definir níveis de urgência;
- Acompanhar tarefas por período;
- Visualizar tarefas em calendário;
- Gerenciar manutenções;
- Acompanhar o status de cada atividade;
- Centralizar informações operacionais.

O projeto foi desenvolvido pensando principalmente em **simplicidade, produtividade e facilidade de uso**.

---

## ✨ Funcionalidades

### 📝 Tarefas

- Criação de tarefas;
- Edição de tarefas;
- Exclusão de tarefas;
- Controle de conclusão;
- Descrição;
- Data;
- Nível de urgência;
- Organização por período.

### 🚨 Níveis de urgência

O sistema trabalha com três níveis:

- 🟢 **Baixa Urgência**
- 🟡 **Média Urgência**
- 🔴 **Alta Urgência**

---

### 📊 Dashboard

O dashboard apresenta uma visão geral das atividades cadastradas.

É possível visualizar:

- Total de tarefas;
- Tarefas pendentes;
- Tarefas concluídas;
- Atividades por período;
- Manutenções;
- Filtros de visualização.

O dashboard diferencia visualmente **tarefas** e **manutenções**.

---

### 🔧 Manutenções

O Simple Task possui um módulo específico para gerenciamento de manutenções.

Cada manutenção pode possuir:

- Título;
- Descrição;
- Edifício;
- Bloco;
- Apartamento;
- Categoria;
- Prioridade;
- Status;
- Tipo de prestador;
- Nome do prestador;
- Telefone;
- Data agendada;
- Observações.

### Status de manutenção

- `Pendente`
- `Em andamento`
- `Agendada`
- `Concluída`

### Tipo de prestador

- Pessoa
- Empresa
